Buzz Toolkit Make your own quiz packs for Buzz! Quiz World

Write your questions, add pictures, choose the rounds and press Generate: you get a package that installs in RPCS3 (the PS3 emulator) like real downloadable content, with the quiz host reading your questions. Host your own MyBuzz server for online quizzes too.

Download the latest release View on GitHub

What it does

Quiz pack generator

Make custom quiz packs: standard, picture, All That Apply and Point Stealer questions, your own running order of rounds, any language code. Out comes an installable .pkg.

Host voice-over

Optionally, the quiz host reads every question, in a voice trained from your own copy of the game. Each line is checked with speech recognition.

Your own MyBuzz server

A self-hosted replacement for the long-closed official servers: online quizzes, leaderboards and buddies for you and your friends.

How it works

  1. InstallUnzip the toolkit and double-click Install.bat (Python 3.11 needed).
  2. Set up from your own gamePoint it at your RPCS3 folder and your own decrypted game file. Nothing from the game is included in the toolkit.
  3. Make a packImport questions from files or free trivia databases, or write your own, in Buzz Pack Studio in your browser.
  4. Generate and playPress Generate, install the package in RPCS3, and play it from the Pack Game menu.

Features

  • Questions from CSV, text, Moodle XML, JSON and more
  • Open Trivia DB and other free question sources
  • Picture questions from your own images
  • Per-pack running orders for the Pack Game menu
  • Checks the game's text limits for you
  • Pack-number protection, so packs never overwrite each other
  • Downloads the official game update from Sony for you
  • Works offline; the server is optional

Questions

Does it include the game or any game files?
No. You need your own copy of Buzz! Quiz World (BCES00645). The toolkit reads what it needs from your copy, on your machine.
Does it work on a real PS3?
Packs are confirmed working on RPCS3. Real consoles are untested so far.
What does it cost?
Nothing. It's free and open source under the MIT licence.
